# devops-bash

Bash scripts for UCSC DevOps Assignment 2.

## Scripts

- `echo.sh` - Echoes a command line parameter
- `ifcmd.sh` - Prints even or odd for a given number
- `fn.sh` - Adds 3 to a given number using a function
- `dirs.sh` - Runs ls -la on a given folder
- `wr.sh` - Creates a folder and writes text into multiple files
